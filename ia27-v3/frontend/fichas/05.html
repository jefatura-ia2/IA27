🗂 Estructuras de Datos en Python

Listas, tuplas, diccionarios y conjuntos — las colecciones fundamentales de Python con sus métodos y actividades prácticas

📋
Lista
Mutable Ordenada Duplicados
Colección modificable de elementos en orden. La más versátil.
📌
Tupla
Inmutable Ordenada Duplicados
Como una lista pero fija. Ideal para datos que no deben cambiar.
📖
Diccionario
Mutable Ordenado Claves únicas
Pares clave→valor. Acceso ultrarrápido por clave.
🔵
Conjunto
Mutable Sin orden Sin duplicados
Elimina duplicados y permite operaciones de conjuntos matemáticos.

📋 Listas — list

Colección ordenada y mutable de elementos. Acepta tipos mixtos y duplicados. Se define con corchetes [ ].

# Crear listas
frutas = ["manzana", "pera", "uva"]
numeros = [10, 20, 30, 40]
mixta  = ["Ana", 16, True]          # tipos mezclados
vacia  = []

# Acceso por índice (empieza en 0)
print(frutas[0])    # "manzana"
print(frutas[-1])   # "uva" (último)
print(frutas[0:2])  # ["manzana", "pera"] (slice)

# Modificar
frutas[1] = "kiwi"  # reemplazar
frutas.append("naranja")   # añadir al final
frutas.insert(0, "fresa")  # insertar en posición
frutas.remove("uva")        # eliminar por valor
ultimo = frutas.pop()         # extraer el último
frutas.sort()                 # ordenar (modifica la lista)
frutas.reverse()              # invertir

# Consultar
print(len(frutas))           # longitud
print("pera" in frutas)      # True/False
print(frutas.count("kiwi")) # nº de apariciones
print(frutas.index("kiwi")) # posición

Métodos principales

📌 Tuplas — tuple

Colección ordenada e inmutable. Una vez creada, no puede modificarse. Se define con paréntesis ( ) o simplemente con comas.

# Crear tuplas
coordenadas = (40.415, -3.703)         # Madrid
rgb_rojo    = (255, 0, 0)
dimensiones = (1920, 1080)
singleton   = (42,)                      # tupla de 1 elem. (coma obligatoria)
sin_parent  = 10, 20, 30               # también es tupla

# Acceso (igual que lista)
print(coordenadas[0])   # 40.415
print(rgb_rojo[-1])     # 0

# Desempaquetado (unpacking)
lat, lon = coordenadas
r, g, b  = rgb_rojo
print(f"Latitud: {lat}, Longitud: {lon}")

# ¿Por qué usarlas? Garantía de inmutabilidad
# coordenadas[0] = 41.0   → ❌ TypeError: 'tuple' object does not support item assignment

# Métodos disponibles (solo dos)
dias = ("lunes", "martes", "lunes", "miércoles")
print(dias.count("lunes"))    # 2
print(dias.index("martes"))   # 1

# Tuplas vs Listas — regla práctica
# ¿Los datos pueden cambiar? → Lista
# ¿Son fijos por definición? → Tupla (colores RGB, coordenadas, versión...)

Cuándo usar tuplas

Caso de usoEjemplo
Coordenadas geográficaspunto = (lat, lon, altitud)
Colores RGB/RGBArojo = (255, 0, 0)
Registros de base de datosfila = (1, "Ana", "Cáceres")
Valores de retorno múltiplesreturn min_val, max_val
Claves de diccionariod[(x, y)] = "casilla"

🎯 Ejemplo práctico — Sistema de colores

PALETA = {
    "rojo":   (220, 38, 38),
    "verde":  (22, 163, 74),
    "azul":   (37, 99, 235),
}
for nombre, (r, g, b) in PALETA.items():

📖 Diccionarios — dict

Colección de pares clave → valor, mutable y ordenada (Python ≥ 3.7). Se define con llaves { } y dos puntos :. Acceso instantáneo por clave.

# Crear diccionario
alumno = {
    "nombre": "Ana",
    "edad":   16,
    "notas":  [8, 9, 7, 8],
    "activo": True
}

# Leer valores
print(alumno["nombre"])             # "Ana"
print(alumno.get("ciudad", "N/A"))  # "N/A" (clave inexistente, sin error)

# Modificar / añadir
alumno["ciudad"] = "Plasencia"      # nueva clave
alumno["edad"]   = 17               # actualizar
alumno.update({"curso": "1ºBach", "grupo": "A"})

# Eliminar
alumno.pop("activo")                # elimina y devuelve el valor
del alumno["ciudad"]               # elimina sin devolver

# Iterar
for clave in alumno.keys():
    print(clave)
for valor in alumno.values():
    print(valor)
for clave, valor in alumno.items():  # ← el más usado
    print(f"{clave}: {valor}")

# Comprobar existencia
if "nombre" in alumno:
    print("Tiene nombre")

Métodos principales

MétodoDescripciónDevuelve
get(k, default)Valor de clave k; devuelve default si no existeValor o default
keys()Todas las clavesdict_keys
values()Todos los valoresdict_values
items()Todos los pares (clave, valor)dict_items
update(d)Añade/actualiza con otro diccionarioNone
pop(k)Elimina clave k y devuelve su valorValor
setdefault(k, v)Devuelve valor de k; si no existe lo crea con vValor
clear()Vacía el diccionarioNone

🎯 Ejemplo práctico — Contador de palabras

texto = "hola mundo hola python mundo hola"
contador = {}
for palabra in texto.split():
    contador[palabra] = contador.get(palabra, 0) + 1

print(contador)
# {'hola': 3, 'mundo': 2, 'python': 1}

# Ordenar por frecuencia (de mayor a menor)
ordenado = sorted(contador.items(), key=lambda x: x[1], reverse=True)
for palabra, veces in ordenado:
    print(f"{palabra}: {'█' * veces} ({veces})")

🔵 Conjuntos — set

Colección mutable, sin orden y sin duplicados. Se define con llaves { } (sin dos puntos). Soporta operaciones matemáticas de conjuntos.

# Crear conjuntos
pares   = {2, 4, 6, 8}
impares = {1, 3, 5, 7}
vacio   = set()               # ⚠️ {} crearía un dict, no un set

# Eliminar duplicados de una lista
lista = [1, 2, 2, 3, 3, 3]
unico = set(lista)            # {1, 2, 3}

# Añadir / eliminar
pares.add(10)                 # añadir elemento
pares.remove(8)               # eliminar (error si no existe)
pares.discard(99)             # eliminar sin error

# Operaciones de conjuntos
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

union         = a | b          # {1,2,3,4,5,6}  ← todos
interseccion  = a & b          # {3,4}          ← comunes
diferencia    = a - b          # {1,2}          ← en a pero no en b
sim_diff      = a ^ b          # {1,2,5,6}      ← en uno solo

# Comparar conjuntos
print({1,2}.issubset(a))      # True  ({1,2} ⊆ a)
print(a.issuperset({1,2}))    # True  (a ⊇ {1,2})
print(a.isdisjoint({7,8}))    # True  (sin elementos comunes)

Operaciones entre conjuntos

OperaciónSímboloMétodo equivalenteResultado
Unióna | ba.union(b)Todos los elementos de ambos
Interseccióna & ba.intersection(b)Solo los comunes
Diferenciaa - ba.difference(b)En a pero no en b
Dif. simétricaa ^ ba.symmetric_difference(b)En uno solo

🎯 Ejemplo práctico — Alumnos por grupos

grupo_A = {"Ana", "Carlos", "María", "Pedro"}
grupo_B = {"Carlos", "Laura", "María", "Juan"}

en_ambos  = grupo_A & grupo_B    # {"Carlos","María"}
en_alguno = grupo_A | grupo_B    # todos (6 alumnos)
solo_A    = grupo_A - grupo_B    # {"Ana","Pedro"}

print(f"En ambos grupos: {en_ambos}")
print(f"Total de alumnos únicos: {len(en_alguno)}")
